# Préparation d'une soumission iOS

Statut : archive Release pour appareil physique préparée, non signée. Aucun lien App Store ni TestFlight actif. Une compilation pour simulateur ne donne pas accès à l'application sur un iPhone.

- Nom : Jarvis.
- Bundle ID : `io.github.raphaelflipo.jarvis`.
- Version : 3.3.0 ; build 33001 ; édition de validation 3.3.0-rc.1.
- Langue principale : français ; catégorie proposée : Productivité.
- Sous-titre proposé : « Votre conversation, en local ».
- Description proposée : « Discutez avec un modèle exécuté sur votre iPhone ou iPad. Jarvis est gratuit et ne nécessite pas de compte. Un premier téléchargement de modèle nécessite Internet. Les conversations sont conservées sur votre appareil. Le modèle léger répond surtout en anglais ; le modèle Qwen3 proposé est mieux adapté au français et nécessite davantage de mémoire. Cette édition ne pilote pas les autres applications et ne recherche pas sur Internet. »
- Assistance et confidentialité : https://raphaelflipo.github.io/jarvis/ (section confidentialité).
- Contact éditeur : r.flipob@gmail.com.
- Pas d'achat intégré, pas de publicité, pas d'analytique ni de compte.

À terminer avec le compte de l'éditeur : confirmer l'équipe et l'adhésion permettant une diffusion publique ; créer l'identifiant et l'app App Store Connect ; produire les signatures et profils adaptés ; tester l'archive sur un iPhone réel ; choisir les modèles et langues présentés selon ces essais ; préparer les captures réelles aux dimensions requises ; vérifier le questionnaire de confidentialité, l'âge et la conformité des modèles ; soumettre à validation. Ne pas présenter les réponses proposées ici comme des formulaires déjà envoyés ou approuvés.

Pour l'examen : aucun compte nécessaire. Choisir le modèle léger et toucher « Télécharger / charger le modèle », puis saisir un message. Le premier chargement nécessite environ 140 Mo ; le second modèle environ 628 Mo. La taille du téléchargement initial et les limites sont visibles avant de commencer. Les téléchargements de modèles joignent Hugging Face et ses domaines de livraison ; ces services peuvent recevoir l'adresse IP et les informations réseau habituelles, mais pas le contenu de la conversation.

La distribution gratuite avec un Personal Team est limitée aux appareils de test et exige un renouvellement régulier des profils ; elle ne fournit pas un canal public durable. Voir la [documentation officielle Apple](https://developer.apple.com/help/account/basics/about-your-developer-account/). Aucune dépense n'est engagée par le projet.
